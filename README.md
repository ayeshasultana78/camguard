# Camguard: Intelligent Monitoring System
Camguard is a smart CCTV study project developed using **OpenCV** and **Haar Cascade Classifiers**. It is designed to perform real-time detection of various subjects in a video stream.

## 🚀 Features
* **Face & Eye Detection**: Real-time identification of human facial features.
* **Pedestrian Tracking**: Detecting full-body movement in video feeds.[cite: 1]
* **Car Detection**: Specialized classification for vehicle monitoring.[cite: 1]
* **Live Feed Processing**: Optimized for low-latency grayscale and color processing.[cite: 1]

## 🛠️ Tech Stack
* **Language**: Python
* **Library**: OpenCV, NumPy[cite: 1]
* **Environment**: Jupyter Notebook / Python 3.x[cite: 1]

## 📂 Project Structure
* `main.py`: The core detection script.[cite: 1]
* `stats/Haarcascades/`: Contains the XML trained models.[cite: 1]
* `stats/image_examples/`: Test images and video files.[cite: 1]
